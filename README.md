## ✨ Funcionalidades da Home

- **Cards Hiper-Personalizados**: Cada projeto possui sua identidade visual única expressa no card (ondas e submarino para Deep Blue, rede neural pulsante para AGV, HUD e mira 3D para Cyberdefender, buraco negro em rotação para Astrophysics Lab e barras de ordenação animadas para Sorting Visualizer).
- **Busca e Filtro em Tempo Real**: Filtre por categorias (*Simulações*, *IA*, *Jogos & 3D*, *Algoritmos*) ou busque instantaneamente pelo título e tags.
- **🎲 Projeto Aleatório**: Sorteador interativo estilo roleta com sintetizador sonoro procedural via Web Audio API.
- **Design Neutro e Moderno**: Interface limpa, responsiva, com sombras sólidas no estilo Neal Agarwal.
